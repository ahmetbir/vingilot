## The design, in one paragraph

A dark, focused workbench. The window is one gradient ground (five selectable
sidebar washes: buzz/graphite/slate/ember/ink; five accents:
ember/orange/mauve/teal/green — ember `#e0a35f` default) on which three
rounded cards float: the **stage** (center), the **dock** (right, or bottom
drawer, or floating — ⌘\\), and the **status bar**. Left of the stage sits the
sidebar (resizable 196–340px): Inbox / Agents / Pull requests / Deck nav rows,
then Projects (with worktree children + run-state dots), Channels, Direct
messages, and a me-footer. The stage hosts four views (⌘1–⌘3 + PRs): **Deck**
(tasks strip + terminal), **Agents** (card grid with live model/token/cost),
**Inbox** (mentions), **Pull requests** (list + timeline detail with merge
box). The dock has six tabs: Crew (channel chat), Diff, Files (tree +
right-click menu), Checks, History (graph/reflog), Run (dev server + docker
services). Typography: Inter for UI, JetBrains Mono for everything monospace.
Fonts ship in-app (no CDN — the mockup's Google Fonts link is mockup-only).

## Key decisions (owner-confirmed or consciously taken)

1. **Dark-first, dark-only shell — but the Theme style gallery survives**
   (owner, 2026-08-29, on the Settings screenshot: "bunlari kullanalim ama
   ya — gecersiz olmus bu kisim"). Force-dark means: pin the resolved theme
   to the DARK member of the selected theme's pair, not to buzz-dark
   unconditionally. The 60-theme Theme style picker keeps working (dark
   variants only); the Vingilot shell palette seeds specifically the default
   buzz-dark; other themes derive their own colors as they always did. The
   wash overlay rides on any theme; the Vingilot accent applies to the Buzz
   themes (non-Buzz themes keep their own accent picker). The now-invalid
   "Color mode" row (System/Light/Dark) reduces honestly to Dark — no dead
   buttons. Old light code paths stay compiled but unreachable.
2. **Status-bar quick actions are configurable canned prompts** (owner,
   verbatim intent): each button = label + prompt template, editable in
   Settings; pressing it types the prompt into the active tmux pane and hits
   Enter. Defaults: Stop, Commit, Create PR. **Review is the exception**: it
   dispatches a task to an external agent — which agent is itself
   configurable — via the Review popover (reviewer picker + instruction
   textarea, both persisted). Review never types into tmux.
3. **Terminal gains splits** (owner: "terminali ikiye bolmeli suruklemeli").
   Split horizontal/vertical inside one tab, draggable divider, DnD (files
   from Finder, text) targets each half independently — extends the existing
   `vingilot_drop` + `nativeDrop.ts` routing.
4. **Terminal scroll bug is in scope** (owner: "scroll duzgun calismiyor") —
   diagnose against the real app first (systematic debugging, not a guess),
   fix rides with Phase 2.
5. **Catppuccin exits.** The inventory proved --primary is stock Catppuccin
   mauve to the bit. The new token layer replaces it; mauve survives only as
   one of the five accent choices (a nod, not a base).
6. **Old chrome is replaced, not themed.** AppSidebar's accordion,
   ProjectStatusBar/ChatStatusBar, TerminalTabStrip get successors, not
   restyles. Their vocabulary (quiet plates, honest doors, lead/name
   truncation, git-letter colors, AttentionDot semantics) carries into the
   successors — the words and semantics were audited good; the material was
   not.

## Phases — each one workflow run, sequential, one mutating lens

Recon for each phase reads this file plus the mockup copy; verify gates on
REAL exit codes + screenshot reads, and re-proves on a different seam.

- **P0 — foundation.** New token layer in `theme.css` (side washes, accents,
  content/term surfaces, ink/mut/bor) mapped onto the existing shadcn token
  names so every unported component inherits the dark shell for free. Inter +
  JetBrains Mono bundled via fontsource. Gradient `.win` ground. Appearance
  tray (wash/accent/crew-position, persisted). Force-dark switch.
- **P1 — shell.** Top bar (traffic lights, back/fwd, centered ⌘K, History /
  Copy-link / Appearance). Floating-card layout with 12px gutters. New
  sidebar (nav rows + Projects/Channels/DMs + me-footer). Resizers (sidebar
  196–340, dock 300–540 right / 170–480 drawer). ⌘B noside, ⌥⌘B zen.
- **P2 — deck view.** Tasks strip (⌘T; a task = a named run/session). New
  terminal tab bar (dot state, model + elapsed on the right). Scratch
  terminal (⌥⌘T, ephemeral, "keeps nothing"). Terminal SPLIT (new). Scroll
  bug: diagnose then fix. This phase touches the fork's own terminal
  features — fable-medium build lens.
- **P3 — dock.** Shell with six tabs + three positions + ⌘\\ float. Crew =
  existing channel chat rendered dockside (messages feature, restyled
  surface only — timeline internals stay upstream's). Diff (PR bar, file
  rows, inline hunks). Files (tree, file-type logos, git badges, context
  menu: Open / Open to the side / Reveal in Finder / Copy path / New
  terminal here / Rename / Ask agent about this / Discard changes / Delete).
  Checks. History (SVG graph + reflog segment). Run (Start Dev ⌘R with
  configurable command, docker services per project, networks & volumes).
- **P4 — status bar + quick actions.** Live segments: project/branch/±/↑,
  working agents, tokens+cost, CI/relay/tmux dots. Configurable canned-prompt
  buttons (decision 2) + Review popover with agent dispatch.
- **P5 — stage views.** Agents grid (live from agent observer stores), Inbox
  (mentions), Pull requests list+detail. OWNER CORRECTION (2026-08-29,
  night): Pull requests does NOT mean the relay-native `projects` feature
  ("experimentsteki projects bambaska bir sey — git hostlamak gibi bisi o").
  It means the REAL pull requests of the repos behind the worktrees, fetched
  via `gh` (preferred) or git — a new vingilot island (Tauri command wrapping
  `gh pr list/view --json` per repo, token never in shell args). Selecting
  the Pull requests nav shows, in the sidebar, the PR list of the repo of
  whichever worktree is selected.
- **P6 — chat everywhere.** DM sheet bottom-right with minimize-to-pill,
  floating crew (⌘\\), palette rework (Recent / Go / Panes / Do something,
  ⌘1–3), scratch markdown (⇧⌘M).
- **P7 — sweep.** Remove the replaced chrome, dead code, stale specs; migrate
  e2e; seams reconciled; ratchet paid; weight-budget kills the owner approves
  (qrcode.react out, virtualization consolidation, mediapipe question).

   the only search affordance (was deferred to P7; pulled forward).

   Settings → Appearance. Keep vingilot-appearance state/setters (Settings
   consumes them); the tray component is removed from the bar (delete or
   park unmounted — prefer delete, it is fork-owned).
3. Covered by the P5 correction above — nothing in P1.1 beyond making sure
   the nav row does not pretend (label may stay, pane says the truth).
4. The workspace sidebar must match the Claude Design mockup EXACTLY
   ("oradaki dizayni birebir istiyorum... cok dikkatli ol"): nav rows, then
   Projects section with each project row carrying its status dot and its
   OWN worktree children indented beneath it (not a flat worktree list, not
   the old Worktrees/Deck accordion headers), Channels, Direct messages,
   me-footer — per mockup Vingilot.html .side anatomy. The Deck accordion's
   Files/History/Chats members remain reachable (they move per the mockup's
   dock in P3; until then keep them accessible without breaking the visual).
   OWNER CLARIFICATION: "hem sol sidebar hem sag sidebar" — the fidelity
   demand covers BOTH sides. The right side is the mockup's dock; P3 builds
   it BIREBIR from Vingilot.html's .dock anatomy (six tabs, three positions,
