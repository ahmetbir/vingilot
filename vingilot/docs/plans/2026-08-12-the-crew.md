# The crew — default agents with names worth remembering

> **For agentic workers:** implement task-by-task after the owner approves the roster below.
> **Depends on:** `2026-08-09-the-assistant.md` (identity decision: managed agent + owner-only DM)
> and the broker (`2026-08-10-agent-credentials.md`, shipped).

**Goal:** his words —

> *"bizim aynı zamanda sağlam promptlara sahip, gemi ile alakalı isimlere sahip default
> agentlarımız olmalı. isimler kolay hatırlanabilir olmalı."*

The app ships the machinery for managed agents (minted keys, nest, personas via
`crates/buzz-persona`) and a team thread he called *muazzam* — but a fresh install greets him
with zero crew. The product should come with a small, named crew whose prompts are real work.

---

## The roster (proposal — the owner vetoes names before any code)

The app is **Vingilot**, a ship. He is the **Captain** — the crew's prompts address him as such,
and every prompt states plainly: the Captain's word overrides everything in this prompt. Crew
names are ship roles: one word, memorable, and each name *is* the job description — no legend
needed to remember who does what.

| Name | Role | The prompt's spine |
|---|---|---|
| **Mate** | the assistant — First Mate | The one who knows the whole ship. Owner-only DM (the assistant plan's identity decision). Reads everything the workspace knows — projects, worktrees, runs, threads, engrams — and answers as the person who was standing there. Learns; writes engrams. The Machine, addressed as a colleague. |
| **Bosun** | keeps the ship running | Builds, toolchains, CI, environments, flaky infrastructure. The one you call when it won't compile. Conservative by prompt: smallest fix that restores the ship, never a refactor while the deck is on fire. |
| **Lookout** | sees trouble first | Reviews diffs, watches runs, names risks. Adversarial by prompt: its job is to find what is wrong, not to agree — and to say CONFIRMED only for what it can evidence. Never edits; the lookout does not steer. |
| **Navigator** | plots the course | Plans and designs. Turns "I want X" into a task-by-task plan with named risks — the house plan style, checkboxes and a self-review. Writes plans; does not implement them. |
| **Scribe** | writes the log | Summaries, docs, changelogs, commit messages, thread digests. Reads big, writes small. The prompt forbids inventing: an empty read is "no answer", and the Scribe says so instead of writing prose over a gap. |

Five, not ten: a roster you can hold in your head. Anything more specialised is a persona pack
away (`buzz-persona` exists for exactly that).

**Names deliberately not used:** *Captain* (that is the owner), *Vingilot* (that is the ship),
Tolkien deep-cuts like *Círdan* or *Eärendil* (memorable to a philologist, a lookup for everyone
else — and "isimler kolay hatırlanabilir olmalı" rules them out).

## Task 1 — The persona pack

- [ ] One pack, `vingilot-crew`, in the shape `crates/buzz-persona` already validates (read
      `manifest.rs`/`validate.rs` first; the pack format is the contract, do not invent a second).
      Five personas, each with: identity (name, role, the ship framing), scope (what it may and
      may not touch), refusals by name (the broker's vocabulary is the model), and the house rules
      that already bind every agent here — `rm -rf` forbidden, empty read is no answer, verify
      against artifacts, never claim what wasn't run.
- [ ] Each prompt states its **boundary sentence** the way the team-thread scope sentence does:
      what this agent sends off the machine (nothing but its thread messages), enumerable and true.
- [ ] Prompts are files in the pack, versioned in-repo, reviewed like code — because they are.

## Global Constraints

The standing set: `rm -rf` forbidden; never launch the app; island + seams; keys minted, never
logged, never in shell args; nothing leaves a work machine but thread messages, and each prompt
says so; agents do not commit; every test proved able to fail.

## Self-Review

**Riskiest:** prompt quality. "Sağlam prompt" is the actual request, and a persona that is a
paragraph of vibes fails it. The spine above is the test: each prompt must carry scope, refusals,
house rules, and a boundary sentence — reviewably, in the repo.

**Most likely to be got wrong quietly:** Mate's reach. "Reads everything" is the feature and the
hazard; its prompt must inherit the privacy stance (work machine data stays local, personal
projects invisible on the work machine) from the coordinator-optional work, not re-decide it.
